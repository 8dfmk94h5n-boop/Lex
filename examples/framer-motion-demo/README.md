# Framer Motion Demo

A minimal Vite + React app demonstrating [framer-motion](https://www.npmjs.com/package/framer-motion),
built to showcase the "Motion-Driven" style entry from the `ui-ux-pro-max`
design database (`src/ui-ux-pro-max/data/styles.csv`, row 15).

Demonstrates:

- **Entrance animation** — cards fade + rise in, staggered 100ms apart
- **Hover microinteraction** — 300ms scale + lift on hover
- **Scroll-linked motion** — hero title scales/fades via `useScroll`

## Usage

```bash
npm install
npm run dev
```

Then open the printed local URL in a browser.

## Build

```bash
npm run build
```
